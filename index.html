ยินดีต้อนรับแอดมิน: -

ย้ายข้อมูล Firebase ระหว่างโปรเจกต์

ใช้ปุ่มสำรองข้อมูลเพื่อดาวน์โหลดข้อมูลจากโปรเจกต์ที่ไฟล์นี้เชื่อมต่ออยู่ จากนั้นเปลี่ยน Firebase config ไปยังอีกโปรเจกต์ เปิดเว็บนี้ใหม่ แล้วนำไฟล์ JSON เข้ามา ข้อมูลเดิมจะไม่ถูกลบ

หมายเหตุ: เครื่องมือนี้ย้ายเฉพาะ Firestore ไม่ย้ายรหัสผ่าน/บัญชี Firebase Authentication ต้องใช้ผู้ดูแลที่มีสิทธิ์อ่านและเขียนข้อมูลในทั้งสองโปรเจกต์

เฉพาะแอดมินหลักเท่านั้นที่เพิ่ม/ถอดสิทธิ์แอดมินได้ บัญชีจะผูกกับ UID Firebase ไม่ใช้รหัสแอดมินซ้ำ

ตรวจชื่อและรหัสพนักงานก่อนส่งลิงก์ตั้งรหัสผ่านใหม่ไปยังอีเมลบัญชี ระบบจะไม่เปิดเผยรหัสผ่านเดิม
